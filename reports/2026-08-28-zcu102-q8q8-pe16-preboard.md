# ZCU102 Q8×Q8 PE16 上板前离线封板报告

日期：2026-08-28  
结论：`PE16_OFFLINE_PREBOARD_PASS / BOARD_AUTHORIZATION_REQUIRED`

## 本阶段结果

- 独立 PE16 全系统位流已生成，XSA 内嵌位流与独立 `.bit` 逐字节哈希一致。
- 200 MHz 实现通过：WNS `+0.067 ns`、WHS `+0.011 ns`、未布线网络 `0`、DRC Error `0`。
- 生成了与 PE16 XSA 匹配的 JTAG-only FSBL，保留已验证的 SPD 动态双 Rank 16 GB DDR 初始化补丁。
- 生成了独立版本化 RAM Linux 包；内核启用 UIO，设备树包含 16 GB DDR、64 MiB DMA 保留区和 `0xA0000000` PE16 控制映射。
- initramfs 中的 AArch64 自检/基准程序与版本化运行时二进制哈希一致；PE16 HLS IP 的 10 个寄存器映射全部匹配。
- JTAG 启动脚本支持显式选择本次 RAM Linux、FSBL、位流和元数据，Tcl 完整性检查通过。
- 规范工作区缺少 Linux/BusyBox 源码，因此构建时只读引用旧独立副本中的干净、固定提交
  （Linux `a19da02c`、BusyBox `1a64f6a2`）；没有同步、覆盖或修改旧副本。
- 最终离线命令输出：

```text
Q8Q8_PE16_BUNDLE_PASS bit_sha256=d8ab6e8215d1ce41f320be8afad51aff5d4e7d90b4135e7994c90d9e1f810f65 memory_bytes=17178820608 dma_bytes=67108864 control=0xA0000000 board_programmed=no
```

## 尚未形成的证据

- 本阶段没有连接、复位或烧录 ZCU102。
- 尚不能声称 PE16 板端数值正确、板端加速比、功耗或温度结果。
- 全尺寸 HLS 顶层 AXI cosim 仍为 `STOP_RESOURCE_RISK`；当前数值证据来自 7/7 C testbench，控制行为来自定向 RTL 仿真。

## 下一门控

用户明确授权上板后，才允许通过 JTAG 进行易失性 RAM 启动。启动脚本不会写入 SD/QSPI，但会复位 PS、配置 PL，并替换当前 RAM 中的运行环境。上板后依次门控：16 GB DDR 识别、PL configured、AXI-Lite `ap_idle`、Linux UIO、板端数值自检、性能/APM 计数、温度与功耗记录。
