# 坐标监督学习型 Token Selector：开发集结论

日期：2026-08-25  
状态：`TEACHER_AND_TRAINING_COMPLETE / DEVELOPMENT_GATE_FAIL / NO_BLIND_TEST / PL_HOLD`

## 实现

- 教师：vision layer-5 的 `|activation × gradient|`，目标为标注坐标的 teacher-forcing NLL。
- 推理特征：四邻域残差、激活能量、Prompt 相关性、归一化 x/y；不读取真值。
- 评分头：`Linear(5,16) → ReLU → Linear(16,1)`，113 参数、96 MAC/group。
- 数据：96图×2任务；按图拆分64图训练、32图校准，同图任务不跨集合。
- 训练：600轮；完整、去文本、去坐标、去区域损失四组消融；共同校准损失选检查点。

归一化为概率质量，再在对数概率上施加温度，避免 softmax 退化为均匀分布。

## 门控结论

从零学习的绝对排序未超过同预算 L2，且75%和87.5%预算均未满足相对full四指标下降不超过2个百分点。
不冻结、不建立新盲集、不进入HLS/RTL。失败原因是单group的一阶梯度显著性不能充分描述多个group
同时删除后的非线性交互，且113参数头对可靠L2排序的改动缺少安全锚点。

下一候选使用 `score = normalized_L2 + residual_MLP(features)`：初始残差为零，行为严格等于L2，
只学习局部改序；对残差幅度做正则，并把L2本身作为消融下界。仍须先过开发精度门再做全新盲测。
