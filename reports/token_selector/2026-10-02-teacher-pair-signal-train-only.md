# Teacher 成对信号可学性审计（train-only，2026-10-02-teacher-pair-signal-train-only）

本轮只做**描述性诊断**：判断同一图片 grounding/pointing 两个 prompt 的现有 dense teacher target 是否提供非零、稳定且空间上可区分的成对信号，以及强弱与异质性。不训练、不调参、不设通过阈值、不读 val/test 特征缓存、不加载模型、不用 GPU、不联网。

## 3. 指标定义

- JS 散度（自然对数/nats）：JS divergence uses natural log (nats); its range is [0, ln 2] = [0, 0.693147], 0 iff the two teacher_soft distributions are equal.
- grid 距离：grid distance uses the row-major flat index convention g -> (row=g // grid_w, col=g % grid_w); it is reported N/A if group_count != grid_h * grid_w for any train pair.
- 对称 KL：0.5·(KL(y_g||y_p) + KL(y_p||y_g))，分母 clamp 到 1e-12。
- TV：0.5·Σ|y_g − y_p|，范围 [0, 1]。
- top-K：K=48/64/96，K>G 时取 min(K,G) 并在 CSV 标记 kK_exceeds_g。
- oracle 互换对照：own KL(y||y)=0，swapped KL(y_g||y_p) 与 KL(y_p||y_g)；严格优势 = swapped KL > 0。

## 7. 解释与限制

- 本审计只回答 teacher pair signal 是否非零、强弱和异质性；**不能**据此声称固定 `prompt_mean_vector` scorer + paired contrastive/delta loss 重训必然成功。
- 现有 teacher 由 **max-over-prompt-token** 生成，已知 prompt/image signal ratio 约 0.27，因此即使 pair signal 非零也可能偏弱。
- 未自创通过阈值；未访问 test 来定阈值；未读取任何 val/test 特征缓存。
- 所有数值都是 internal teacher-target 诊断，不是 CV-Bench 任务精度，也不代表 student 可学。
