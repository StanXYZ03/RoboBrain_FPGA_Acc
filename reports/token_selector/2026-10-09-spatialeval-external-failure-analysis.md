# SpatialEval 外部确认失败归因

- 结论：`CURRENT_K96_SELECTOR_REJECTED_BY_EXTERNAL_CONFIRMATION`。当前 K96 v2 不能作为论文主方案继续晋级。
- 数据：三个官方可评分任务各 1500 条，共 4500 条；三臂合计 13500 次推理。
- 该 test 已经解封并分析，今后不得用于调参或再次充当未见外部确认集。

## 质量结果

- Dense：`0.583778`。
- L2@K96：`0.439111`。
- v2@K96：`0.434444`。
- v2/Dense：`0.744195`，即保留 `74.42%`，低于冻结门槛 `90%`。
- v2-L2：`-0.004667`，95% CI `[-0.013778, +0.004444]`；没有优于 L2 的证据。
- 配对结果（全体）：v2 独对 `213` 条，L2 独对 `234` 条，两者都对 `1742` 条。

## Token 与时延

- Dense 平均视觉 token：`468.98`；v2 固定输出 `96`，总体减少 `79.53%`。
- Dense 实测 mean elapsed：`1426.78 ms`；v2：`1472.96 ms`，当前软件路径反而慢 `3.24%`。
- Dense Decode：`1220.92 ms`，占总时延 `85.57%`。即使所有非 Decode 阶段都变成零开销，Amdahl 上限也只有 `1.169x`。
- Dense 有 `4231/4500` 条、v2 有 `4310/4500` 条输出撞到 64-token 上限。Decode 主导是本次官方解释型 Prompt 的真实结果，但不能直接外推到只输出坐标或动作码的短结构化任务。
- Prefill 从 `80.78 ms` 降至 `37.84 ms`，加速 `2.135x`，但只节省 `42.94 ms`。
- v2 CPU selector 往返均值 `81.07 ms`。把它乐观地直接减为零，总加速也仅约 `1.025x`；这不是 FPGA 预测。

## 决策

1. 停止将当前固定 K96 v2 作为主创新点继续晋级；外部质量门已明确失败。
2. 不在 SpatialEval test 上调 K、权重或锚点，避免把外部集变成发展集。
3. 在原发展数据上研究自适应预算和空间关系保持，并与结构化短解码或非自回归动作头联合设计。
4. 下一版方法冻结后，必须换一个从未观察过的公开基准做新的外部确认。
5. Jetson/ZCU102 到位后只验证真实链路与功耗，不能用上板结果推翻本次质量失败。
